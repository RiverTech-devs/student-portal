# Student Portal — Full Audit, Feature Breakdown & Competitive Comparison
**Date:** 2026-07-09 · **Repo:** `RiverTech-devs/student-portal` @ `512a501` · **Site:** rivertech.me

This audit was run as 8 parallel passes (student portal, portal core, Riven/RTC, Supabase backend, games, enrollment/tools/viewers, feature inventory, market research). A full inline-`<script>` syntax sweep of all 30 HTML files and every standalone JS file passed clean — **no page-crashing syntax errors**. All findings below are new unless noted; items already tracked in `AUDIT_NOTES.md` were verified, not re-reported.

### HIGH

**Security / XSS**
- **H-1 Open email/phishing relay.** `send-notification-email` only checks a bearer/apikey exists — never the caller's role or recipient relationship, and takes `to/subject/html` straight from the body. With the public anon key, anyone sends attacker-HTML from DKIM-signed `notifications@rivertech.me`. `supabase/functions/send-notification-email/index.ts:33,125,617`
- **H-2 Stored XSS in submission grading modals.** `submission.content/file_name/file_url` interpolated raw into the teacher grading UI. `portal/index.html:21210,21220,22489,22500`
- **H-3 Stored XSS in testing-center grading.** `extensions/testing-center.html` (live-iframed) has **no `escapeHtml` at all**; student written answers/feedback/titles run in the teacher's token context. `testing-center.html:1649,2146,2153`
- **H-4 Stored XSS in admin enrollment review.** Attacker-controlled `school_year` (not constrained by the anon INSERT policy) rendered unescaped in the admin dropdown + detail header. `portal/index.html:29538,29590`
- **H-5 Stored XSS in discussion replies + unescaped student names** across attendance/class-management renderers (also breaks buttons on apostrophe names). `portal/index.html:14658,34286,16198,…`
- **H-6 Realtime "Riven bubble" XSS** via `metadata.sender_id` in an `onclick`, combined with the open notification INSERT (C-3). `portal/index.html:12527`
- **H-7 postMessage trusts any origin + leaks tokens.** The global message listener validates neither `event.origin` nor `event.source` before DB-writing handlers; `sendTestingCenterAuth` posts Supabase access+refresh tokens with `targetOrigin '*'`. `portal/index.html:2768,3795`
- **H-8 Hardcoded Google Gemini API key in client source** — any student can lift it and burn the school's billing. `games/teacher-challenge.html:1681`
- **H-9 Every teacher can dump every student's plaintext games PIN**, unscoped by class — the PIN is the sole login credential, so this is school-wide impersonation + FERPA PII. `zz_refresh_admin_bank_list_students.sql:32`

**Correctness / data integrity**
- **H-10 Account activation loop.** Self-serve "Activate Account" does a direct `UPDATE user_profiles SET account_status/can_login` that the `protect_user_profile_columns` trigger silently reverts for anon/authenticated callers; login then permanently rejects with "not activated." The `reactivate_student()` RPC is never called. `index.html:2061`
- **H-11 Gauntlet/Recall RTC silently dead (mirror of C-1).** The client awards via `earn_skill`, which the hardened RPC rejects from student callers; error swallowed, student gets 0 RTC for completing a full gauntlet. `index.html:5216`
- **H-12 auth-uid vs profile-id split** across `assignment_submissions` (and message notifications): student writes under auth uid, teacher reads under profile id → teacher sees "Not submitted," grades a phantom row, `calculate_class_grade` excludes the real submission. Fixed for `assignment_students`, not these paths. `portal/index.html:21869,4061,…`
- **H-13 Dead "Open Math Dojo" buttons** call `window.portal.showSection('games')` — no such method exists (only `showTab`); every click throws. `index.html:2503,2553,2559`
- **H-14 `skill_progress` upserts omit `onConflict`** → degrade to INSERT and 409 against the unique constraint for any existing skill; gauntlet demotions and unlock writes silently fail. `index.html:5172,5410`
- **H-15 Attendance delete-then-insert with unchecked delete** — if the insert fails after the delete, the whole class/date/period's attendance is permanently erased (same pattern: schedule save, edit-assignment students). `portal/index.html:34940,32092,19930`
- **H-16 Mixed-status attendance never saves** — conditional per-row keys violate PostgREST's uniform-payload rule for bulk upsert; any roster with present + absent fails entirely. `portal/index.html:34411`

## PART 2 — FEATURE BREAKDOWN (what it does, and where)

**Stack:** vanilla JS/HTML/CSS, no build step; Supabase (Postgres + Auth + RLS + Realtime + Edge Functions); GitHub Pages. ~45 tables, 149 migrations, 6 edge functions, 10 games, a 680-node/1,119-edge/69-cluster curriculum graph. Two frontends: root `index.html` (student, ~5.7k lines) and `portal/index.html` (staff/parent monolith, ~53k lines).

**Anonymous / public:** multi-step enrollment application (`enrollment/index.html`); PIN login for young students (4-char PIN, ~923K combos, anon edge function); magic-link email confirm; password reset; curriculum graph viewers (2D constellation, 3D network).

**Student:** dashboard, own grades (per quarter), personal curriculum skill graph (states: locked/available/in_progress/activated/mastered/needs_review), 10 games, RTC wallet + cosmetics (avatar/title/3 badge slots) + time-limited privileges, class rosters, homework submission, assigned tests, direct messaging, activities, documents, profile + theme.

**Games (all write real data):** Math Dojo (202 lessons/204 generators, sub-skill gated), Mathletics, Mathspire (RPG), Wasteland Adventure (tactical math), English Lyceum, Practice Pilot, Teacher Challenge, Clockwork Defense, Dimension Shift, Riutiz (card game, the one wired to the arcade RTC/leaderboard path). They feed `skill_progress` and award RTC.

**Parent:** dashboard for linked children, children's classes, child grades/skills/notes, message teachers, activities, documents.

**Teacher:** per-class gradebook (quarter grades, weights, honors/AP bumps, overrides via security-definer RPCs), class notes + per-class CSV spreadsheets (`teacher_sheets`), assignments (score-tiered RTC), testing center (assign/grade, per-question grades), attendance (daily + period, auto-absence alerts), "My Students" hub, unified Notes feed (merges new + 3 legacy note tables, multi-filter), messaging + broadcasts, RTC Bank Helper, IRL store, activities & facility booking, and **Riven** — a local NLP terminal (regex + client-side MiniLM embedding fallback) that READS student/balance/history/attendance/grades/rosters/contacts/notes and WRITES RTC award/deduct/transfer, notes, attendance, enroll/unenroll, class create/deactivate, grade overrides, contact info — all with an undo stack and a confirmation gate on sensitive writes.

**Admin:** everything above plus user management, create/activate inactive students, hard-delete accounts (edge function), school settings/theme, **report cards & transcripts** (built), student records, enrollment review/approval, discipline strikes, facilities, full RTC management (cosmetics/privileges/spend categories/set balances), materials requests, bug reports.

**Platform:** realtime notification bell; email via edge functions (message forwarding, 24h due-date reminders, overdue-assignment parent alerts); Google Drive assignment uploads; 6 themes + 5 button schemes; undo; localStorage persistence; RLS as the load-bearing security model.

**Roadmap (planned, not built):** payments/tuition/fees, SMS + mass email, SSO (Google/Microsoft), PWA/mobile app, WCAG 2.1 AA, custom report builder, multi-language; then cafeteria, transportation, library, admissions CRM, conference scheduling, permission slips, standards-based grading, IEP/504, and more.

## PART 3 — HOW IT COMPARES (small private school, ~20–200 students)

### The direct competitors (small-school SIS)
- **Gradelink** — small/faith-school focus; SIS, gradebook, report cards + standards-based cards + transcripts, billing/tuition, state + NCEA reporting, health, discipline, lunch, light IEP. **No LMS, no AI.** ~$121–210/mo flat (~$20–24/student/yr); online enrollment & SMS are paid add-ons. Complaint: dated UI, clunky scheduling.
- **Sycamore School** — deepest all-in-one for independents (300+ features), admissions + financial aid, tuition billing/autopay, deepest Google Classroom sync. **No AI.** ~$4/student/mo (~$48/yr). Complaint: UI "resembles Windows 3.5," built-in email "grossly insecure."
- **FACTS SIS (RenWeb)** — private/faith incumbent (12,000+ schools); strongest scheduler, tuition management + Grant & Aid is its moat. **No consumer AI.** Quote-only, ~$60–72/student/yr, "nickel-and-dime" reputation. Complaint: "designed in the 90s," cost creep.

*(District-scale — PowerSchool, Infinite Campus, Skyward — are the feature ceiling but the wrong price class at this size, $10–20K+/yr. PowerSchool also suffered the Dec-2024 breach of ~62M students, which is reshaping buyer trust toward privacy.)*

### 2026 table stakes vs where the portal stands

| Table stake | Portal |
|---|---|
| Student records, attendance, gradebook, parent/student portal, messaging | ✅ at/above parity |
| **Report cards + transcripts** (also required via accreditation) | ✅ **built** |
| **Tuition/billing** (the #1 reason small schools buy an SIS) | ❌ **missing — biggest gap** |
| Encryption at rest, MFA, audit logs, COPPA posture | ⚠️ RLS-strong but no staff MFA/SSO; COPPA AI-consent rule now in force |
| SSO / Clever / ClassLink / OneRoster | ❌ none (Google/MS SSO matters most at this size) |
| Native mobile apps | ⚠️ responsive web + push is acceptable in 2026 — **verify push actually fires** |
| State reporting, IEP/504, auto-scheduling | ➖ low priority for a small private school; a roster CSV + accommodation notes suffice |

### Where it genuinely beats the field
1. **Gamified prerequisite-mastery graph + 10 in-house games + a virtual economy** — near-unique in 2026. No SIS ships it; ClassDojo is behavior-only and ages out ~grade 5; Classcraft (the one RPG-economy platform) sunset its economy June 2024.
2. **True mastery modeling with prerequisite edges** — structurally deeper than Canvas/Schoology standards-mastery, which don't model dependencies.
3. **Local (private) NLP teacher assistant** — every small-school competitor ships **zero AI**, and the big players' AI is cloud + often paid; a local assistant is a strong privacy story in the post-breach year.
4. **Facility booking + PIN login for young students** — absent across the entire comparison set.
5. **Modern UI** — every incumbent's most consistent complaint is a dated interface; that's an open flank.

### Bottom line
It is **not a drop-in SIS today** — it's missing tuition/billing (the killer small-school feature) and, though report cards/transcripts are built, they need verification against accreditation formats. But on the differentiator axis it is arguably the most innovative product in the comparison set. Closing **billing** + confirming **report-card/transcript** output + adding **Google/MS SSO** (and verifying mobile push) would move it from "innovative supplement" to "complete small-private-school SIS that also does things no competitor can." The IEP, state-reporting, and auto-scheduling "gaps" are largely irrelevant at this scale and shouldn't be prioritized.

### Suggested fix order
1. **C-1 / H-11** — cap `earn_skill` server-side and route legitimate gauntlet awards through a system-granted path (they're two ends of the same broken gate).
2. **C-2, C-3, H-1..H-6** — one shared quote-safe `escapeHtml` at every user-string interpolation + tighten the notification INSERT policy + role-gate the email function. This closes the whole XSS/relay family.
3. **C-4, H-30** — fix sibling enrollment submit; surface & persist emergency medical info.
4. **H-10, H-23** — fix the activation loop and the `/student-portal/` redirect paths (auth is broken on the live domain today).
5. **H-15/H-16/H-17** — attendance delete-safety, mixed-status upsert, and school-scale pagination before real enrollment load.
6. **H-21/H-22** — Riven relay-verb and question-phrasing guards (recent regression, actively mutates data).
